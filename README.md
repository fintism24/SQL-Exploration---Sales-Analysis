# SQL Exploration - Sales Analysis

**Code:** [Click Here](https://github.com/fintism24/SQL-Exploration---Sales-Analysis/blob/main/Sales%20Analysis.sql)

**Goal:** To conduct a sales analysis by exploring the data using SQL.

**Description:** Using the 'Retail Sales Analysis' dataset [Link Here](https://www.kaggle.com/datasets/sahirmaharajj/retail-sales-analysis) to explore the dataset to do a sales analysis on the date present. The dataset include the Year & Month of purchase, Item Description, Item Type, the Retail and Warehouse sales of each item and if any item was Retail Transfered or not. I loaded the dataset into mySQL and create the table and I explored the dataset to find out what years saw the most and least amount of sales, Which items sold the most and least overall and for each year and which items had the most retail transfers per year.

**Skills:** Database creation, Data exploration.

**Tech:** mySQL, SQL, GROUP BY, ORDER BY, FORMAT, WHERE. ALTER

**Conclusion:** In conclusion my analysis showed that Corona Beer had the most reatil sales, Michelob Ultra Beer had the most warehouse sales, 2019 saw the highest amount of overall sales, Liqour was the highest selling item type and 2019 saw the highest amount of retail transfers compared to others.
